# The Farmer Was Replaced

A small browser game where the player must reclaim a farm from aggressive replacement drones.

## How to play
- Move with **WASD** or **Arrow keys**.
- Collect all **8 crops**.
- Reach the **barn** to win before the timer runs out.
- Avoid drones or your health will drop.
- Press **Space** for a pulse that pushes nearby drones away.

## Play online
This repository is configured for GitHub Pages. Once Pages deployment finishes, the game can be opened from the repository's Pages URL.

## Run locally
Open `index.html` in a browser, or use a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
